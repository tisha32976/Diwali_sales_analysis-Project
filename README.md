# Diwali Sales Analysis

##  Overview
This project analyzes Diwali sales data using Python to understand customer purchasing behavior and sales trends during the festive season.



## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

##  Analysis Performed
- Data Cleaning & Preprocessing
- Handling Missing Values
- Exploratory Data Analysis (EDA)
- Customer Demographic Analysis
- Sales Trend Visualization

---

## Key Insights
- Female customers contributed more to overall sales.
- Customers aged 26–35 years were the most active buyers.
- Married women had higher purchasing power.
- Uttar Pradesh, Maharashtra, and Karnataka generated high sales.
- IT, Healthcare, and Aviation professionals were major buyers.
